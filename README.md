# Gelaender

Static band website for Gelaender.

## Stack

- Frontend: HTML, CSS, JavaScript
- Hosting: Cloudflare Pages
- Integrations: public Google Calendar embed, YouTube no-cookie embeds

## Current Status

- Static-only deployment
- No backend runtime
- No database
- Security headers shipped via frontend/\_headers
